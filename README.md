# Laboratorio de Reproducción y Conservación Genética — Coyoacán

Proyecto integral de conservación genética, restauración ecológica y economía comunitaria para evitar la extinción funcional del ajolote mexicano (Ambystoma mexicanum) en los humedales de Xochimilco.

## Contenido

1. Proyecto integral
2. Historia: Doña Josefina y Don Roberto
3. Banco genético: 11 familias genéticas
4. Fenotipo hipermelanoide
5. Diversidad genética del laboratorio
6. Colaboraciones científicas (CINVESTAV, CORENA)
7. Impacto social, ambiental y económico
8. Expansión Coyoacán → Xochimilco
